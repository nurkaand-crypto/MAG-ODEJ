## ⚡ НАЧАЛО РАБОТЫ (5 минут)

### Шаг 1️⃣ : Создайте Telegram бота

1. Откройте Telegram, найдите `@BotFather`
2. Отправьте `/newbot`
3. Введите имя: `МАГ-ОДЕЖ бот`
4. Введите username: `mag_odezh_bot`
5. **Скопируйте токен**: `123456789:ABCDEFGHijklmnopqrstuvwxyz-1234567890`

### Шаг 2️⃣ : Получите ваш Chat ID

- Найдите `@userinfobot` в Telegram
- Отправьте ему любое сообщение
- Скопируйте ваш ID из ответа: `123456789`

### Шаг 3️⃣ : Заполните .env файл

```env
TELEGRAM_BOT_TOKEN=123456789:ABCDEFGHijklmnopqrstuvwxyz-1234567890
TELEGRAM_BOT_USERNAME=mag_odezh_bot
TELEGRAM_CHAT_ID=123456789
SECRET_KEY=change-me-to-random-string
```

### Шаг 4️⃣ : Установите зависимости

```bash
pip install -r requirements.txt
```

### Шаг 5️⃣ : Запустите!

**Windows:**
```bash
run.bat
```

**Linux/Mac:**
```bash
bash run_unix.sh
```

**Или вручную:**
```bash
python main.py
```

## 🎯 Как работает тех. часть

### Архитектура

```
Браузер                 Сервер                  Telegram
   ↓                      ↓                        ↓
[Корзина]            [Flask]  ----→  [Telegram Bot API]
   ↓                      ↓                        ↓
[Оформить]           [Заказ]  ----→   [Пользователь]
   ↓                      ↓                        ↓
[Имя]                [Создание]  ←----  [Подтверждение]
   ↓                      ↓                        ↓
[Отправить]          [Уведомление admin]  [Завершение]
```

      "size": "M",
      "price": 2499,
      "quantity": 1,
      "emoji": "👖"
    }
  ],
  "total": 2999,
  "status": "pending",
  "created_at": "29.04.2024 12:05:34"

## 🔐 Безопасность

✅ Токен бота хранится в `.env` (не в коде)
✅ `.env` не коммитится в Git
✅ Заказы хранятся на сервере (не передаются в браузер)
✅ Chat ID используется только на сервере
✅ HTTPS рекомендуется для production
