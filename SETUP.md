## 💾 Установка

### Шаг 1: Проверка Python

Откройте терминал/командную строку и выполните:

```bash
python --version
```

Должна вывести версию 3.8 или выше. Если команда не найдена, установите Python.

### Шаг 2: Установка зависимостей

Перейдите в папку проекта и выполните:

```bash
pip install -r requirements.txt
```

Это установит:
- Flask (веб-фреймворк)
- python-telegram-bot (для Telegram интеграции)
- python-dotenv (для управления переменными окружения)

## 🤖 Настройка Telegram

### Получение Bot Token

1. **Откройте Telegram** и найдите пользователя `@BotFather`

2. **Отправьте команду**: `/newbot`

3. **Ответьте на вопросы**:
   - Как назвать вашего бота? → например: `MAG ODEZH Shop Bot`
   - Какой будет username бота? → например: `mag_odezh_shop_bot`

4. **Скопируйте полученный токен** (выглядит как: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`)

### Получение Chat ID

1. **Отправьте своему боту** любое сообщение (например, `/start`)

2. **Откройте браузер** и перейдите по ссылке:
   ```
   https://api.telegram.org/bot<ВАШ_TOKEN>/getUpdates
   ```
   Замените `<ВАШ_TOKEN>` на полученный токен.

3. **Найдите в ответе строку** с `"id"` - это ваш Chat ID (например: `123456789`)

### Добавление данных в код

Откройте `main.py` в текстовом редакторе и найдите строки:

```python
TELEGRAM_BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
TELEGRAM_CHAT_ID = "YOUR_CHAT_ID"
```

Замените на ваши данные:

```python
TELEGRAM_BOT_TOKEN = "123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"
TELEGRAM_CHAT_ID = "123456789"
```

## 📧 Настройка Email (Gmail)

### Включение двухфакторной аутентификации

1. **Откройте** [Google Account Security](https://myaccount.google.com/security)

2. **Найдите раздел** "Двухфакторная аутентификация"

3. **Нажмите** "Включить двухфакторную аутентификацию" и следуйте инструкциям

### Создание пароля приложения

1. **После включения 2FA**, вернитесь в [Google Account Security](https://myaccount.google.com/security)

2. **Найдите раздел** "Пароли приложений" (должен появиться после включения 2FA)

3. **Выберите**:
   - Приложение: Mail
   - Устройство: Windows/Mac/Linux

4. **Скопируйте** сгенерированный пароль (16 символов с пробелами)

### Добавление данных в код

Откройте `main.py` и найдите строки:

```python
EMAIL_SENDER = "your_email@gmail.com"
EMAIL_PASSWORD = "your_app_password"
```

Замените на ваши данные:

```python
EMAIL_SENDER = "example@gmail.com"
EMAIL_PASSWORD = "abcd efgh ijkl mnop"
```

⚠️ **ВАЖНО**: Используйте пароль приложения, НЕ обычный пароль от аккаунта!

## 🐛 Решение проблем

### Проблема: "ModuleNotFoundError: No module named 'flask'"

**Решение**:
```bash
pip install -r requirements.txt
```

### Проблема: Порт 5000 уже используется

**Решение**: Отредактируйте последнюю строку в `main.py`:
```python
app.run(debug=True, host='0.0.0.0', port=5001)  # Измените на другой порт
```

### Проблема: Email не отправляется

**Решение**:
- Проверьте, включена ли двухфакторная аутентификация
- Используйте пароль приложения, а не обычный пароль
- Проверьте в коде, что EMAIL_SENDER и EMAIL_PASSWORD верные

### Проблема: Telegram не отправляет уведомления

**Решение**:
- Проверьте, что TELEGRAM_BOT_TOKEN верный
- Проверьте, что TELEGRAM_CHAT_ID верный
- Отправьте своему боту сообщение `/start`
- Попробуйте получить обновления: `https://api.telegram.org/bot<TOKEN>/getUpdates`

### Проблема: Товары не добавляются в корзину

**Решение**:
- Проверьте консоль браузера (F12 → Console) на ошибки
- Убедитесь, что localStorage включён в браузере
- Попробуйте использовать другой браузер
