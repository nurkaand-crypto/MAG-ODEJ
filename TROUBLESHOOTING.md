# 🔧 Решение проблем - Telegram интеграция

## 🚨 Частые проблемы и решения

### ❌ Приложение не запускается

**Проблема:** `ModuleNotFoundError: No module named 'flask'`

**Решение:**
```bash
# Установите все зависимости
pip install -r requirements.txt

# Проверьте что установилось
pip list | grep -i flask
```

---

### ❌ Telegram бот не отвечает

**Проблема:** Ссылка на бота открывается, но сообщения не приходят

**Решение:**
1. Проверьте токен:
   ```bash
   curl https://api.telegram.org/botYOUR_TOKEN/getMe
   ```
   Должен вернуться:
   ```json
   {"ok":true,"result":{"id":123456789,"is_bot":true,"first_name":"МАГ"}}
   ```

2. Проверьте что бот запущен:
   ```bash
   python check_setup.py
   ```

3. Перезагрузите приложение: `Ctrl+C` и `python main.py`

---

### ❌ "Port 5000 is already in use"

**Проблема:** Порт 5000 занят другим процессом

**Решение (Windows):**
```bash
# Найти процесс на порте 5000
netstat -ano | findstr :5000

# Убить процесс (замените PID на число из вывода выше)
taskkill /PID 12345 /F
```

**Решение (Linux/Mac):**
```bash
# Найти процесс
lsof -i :5000

# Убить процесс
kill -9 <PID>
```

**Альтернатива:** Используйте другой порт в `main.py`:
```python
app.run(port=5001)
```

---

### ❌ "TELEGRAM_BOT_TOKEN не установлен"

**Проблема:** Приложение выводит предупреждение о токене

**Решение:**
1. Проверьте что файл `.env` существует:
   ```bash
   # Windows
   dir .env
   
   # Linux/Mac
   ls -la .env
   ```

2. Если его нет, создайте из примера:
   ```bash
   cp .env.example .env
   ```

3. Откройте `.env` в текстовом редакторе и заполните:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCDEFGHijklmnopqrstuvwxyz-1234567890
   TELEGRAM_BOT_USERNAME=mag_odezh_bot
   TELEGRAM_CHAT_ID=123456789
   ```

4. Сохраните файл

### ❌ Admin не получает уведомления

**Проблема:** Администратор не видит уведомления о новых заказах

**Решение:**
1. Проверьте что `TELEGRAM_CHAT_ID` правильный:
   ```bash
   # Найдите свой ID через @userinfobot
   ```

2. Убедитесь что заполнена переменная в `.env`:
   ```env
   TELEGRAM_CHAT_ID=123456789
   ```

3. Перезагрузите приложение

4. Сделайте тестовый заказ

### ❌ JavaScript консоль выводит ошибки

**Проблема:** В консоли браузера видны ошибки JavaScript

**Решение:**
1. Откройте DevTools браузера: `F12`
2. Перейдите на вкладку "Console"
3. Посмотрите ошибку
4. Проверьте что:
   - Браузер может достучаться до сервера (`http://localhost:5000`)
   - Корзина загружается правильно
   - Форма для ввода имени видна

---

### ❌ Заказ не появляется в Telegram

**Проблема:** Заказ создался, но сообщение не пришло в Telegram

**Решение:**
1. Проверьте что вы подписаны на бота:
   - Найдите `@mag_odezh_bot` в Telegram
   - Нажмите "Начать" (/start)

2. Проверьте логи сервера на ошибки

3. Если видите ошибку типа "Chat not found":
   - Проверьте что `TELEGRAM_BOT_USERNAME` правильный
   - Убедитесь что имя не содержит `@`

---

### ❌ "Invalid token" ошибка

**Проблема:** Telegram API возвращает "Invalid token"

**Решение:**
1. Проверьте что скопировали полный токен:
   ```
   ✓ Правильно:   123456789:ABCDEFGHijklmnopqrstuvwxyz-1234567890
   ✗ Неправильно: 123456789:ABCDEF... (обрезано)
   ```

2. Получите новый токен у @BotFather:
   - Команда `/mybots`
   - Выберите вашего бота
   - Нажмите "Edit Token"

3. Замените токен в `.env` файле

---

### ❌ Браузер выдает "Connection refused"

**Проблема:** Браузер не может подключиться к серверу

**Решение:**
1. Проверьте что Flask запущен:
   ```
   Должны видеть строку:
   * Running on http://0.0.0.0:5000
   ```

2. Попробуйте открыть `http://127.0.0.1:5000` вместо `localhost`

3. Проверьте что брандмауэр не блокирует порт 5000

---

### ❌ "CORS error" в консоли браузера

**Проблема:** Браузер выдает ошибку CORS (кросс-доменности)

**Решение:**
Эта ошибка обычно не появляется локально. Если вы на production:

1. Установите Flask-CORS:
   ```bash
   pip install flask-cors
   ```

2. Добавьте в `main.py`:
   ```python
   from flask_cors import CORS
   CORS(app)
   ```

---

### ❌ Виртуальное окружение не активируется

**Проблема:** Команда `activate` не работает

**Решение:**
1. Переустановите виртуальное окружение:
   ```bash
   # Удалите старое
   rm -r venv
   
   # Создайте новое
   python -m venv venv
   
   # Windows активация
   venv\Scripts\activate
   
   # Linux/Mac активация
   source venv/bin/activate
   ```

2. Убедитесь что видите `(venv)` в начале строки

## 📝 Логирование ошибок

Если вы видите ошибку, попробуйте:

1. **Включить режим debug:**
   ```python
   app.run(debug=True)
   ```

2. **Сохранить логи в файл:**
   ```python
   logging.basicConfig(
       filename='error.log',
       level=logging.DEBUG
   )
   ```

3. **Проверить логи:**
   ```bash
   tail -f error.log
   ```

## 🌐 Проблемы в Production

### "403 Forbidden" при webhook

**Решение:**
Убедитесь что URL webhook начинается с `https://` (не `http://`)

### Database errors

**Решение:**
Используйте SQLite для простоты или PostgreSQL для production:
```python
import sqlite3
conn = sqlite3.connect('orders.db')
```

### Telegram webhook "Couldn't connect to <URL>"

**Решение:**
1. Проверьте что сервер доступен:
   ```bash
   curl https://your-domain.com
   ```

2. Убедитесь что firewall открыт для Telegram IP адресов

3. Проверьте SSL сертификат (Let's Encrypt)
