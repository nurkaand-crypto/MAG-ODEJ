## ⚡ Быстрый старт

1. **Создайте бота в Telegram** (см. раздел ниже)
2. **Отредактируйте `.env` файл**:
   ```bash
   cp .env.example .env
   # Откройте .env в текстовом редакторе и заполните:
   # - TELEGRAM_BOT_TOKEN
   # - TELEGRAM_BOT_USERNAME
   # - TELEGRAM_CHAT_ID (для админ-уведомлений)
   ```
3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Запустите приложение**:
   ```bash
   python main.py
   ```
5. **Откройте в браузере**: `http://localhost:5000`

## 🤖 Создание Telegram бота

### Шаг 1: Создайте бота у BotFather

1. Откройте Telegram и найдите `@BotFather`
2. Отправьте команду `/newbot`
3. BotFather попросит имя бота, введите что-то вроде: `МАГ-ОДЕЖ бот`
4. Затем введите username, например: `mag_odezh_bot` (должен заканчиваться на `_bot`)
5. **Скопируйте токен**, который выглядит примерно так:
   ```
   123456789:ABCDEFGHijklmnopqrstuvwxyz-1234567890
   ```

### Шаг 2: Получите свой Chat ID

Есть несколько способов:

**Способ 1: Через @userinfobot**
1. Найдите в Telegram `@userinfobot`
2. Отправьте ему любое сообщение
3. Бот вернёт вашу информацию, включая ID

**Способ 2: Через getUpdates**
```bash
curl https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
```

Замените `<YOUR_TOKEN>` на ваш токен. Ваш ID будет в поле `"from":{"id":123456789}`

### Шаг 3: Заполните `.env` файл

```env
# МАГ-ОДЕЖ - Telegram Bot Configuration

# Токен от BotFather
TELEGRAM_BOT_TOKEN=123456789:ABCDEFGHijklmnopqrstuvwxyz-1234567890

# Имя бота (без @)
TELEGRAM_BOT_USERNAME=mag_odezh_bot

# Ваш Chat ID (для админ-уведомлений)
TELEGRAM_CHAT_ID=123456789

# Flask Secret Key
SECRET_KEY=change-me-to-random-string

# Webhook URL (для production)
WEBHOOK_URL=https://your-domain.com
```

## 🔄 Как это работает

### Процесс оформления заказа

```
1. Пользователь выбирает товары → добавляет в корзину
2. Переходит на страницу корзины
3. Вводит своё имя
4. Нажимает кнопку "Оформить заказ"
   ↓
5. Заказ создаётся на сервере
6. На экран выводится номер заказа и ссылка на Telegram бота
7. Пользователь переходит в Telegram бота
   ↓
8. В боте отправляется полная информация о заказе
9. Пользователь подтверждает контактные данные
10. Оплачивает заказ в боте
    ↓
11. Администратор получает уведомление о новом заказе
12. Обрабатывает и отправляет заказ
```

### Структура данных заказа

```json
{
  "id": "20240429120534",
  "fullName": "Иван Петров",
  "items": [
    {
      "id": 1712233534000,

      "emoji": "👖"
    }
  ],
  "total": 2999,
  "status": "pending",
  "created_at": "29.04.2024 12:05:34"
```

## 🔌 API Endpoints

### POST /create_order
Создаёт новый заказ

**Request:**
```json
{
  "fullName": "Иван Петров",
  "items": [
    {
      "productId": 2,
      "name": "Джинсы",
      "size": "M",
      "price": 2499,
      "quantity": 1,
      "emoji": "👖"
    }
  ],
  "total": 2999
}
```

**Response:**
```json
{
  "success": true,
  "order_id": "20240429120534",
  "telegram_link": "https://t.me/mag_odezh_bot?start=20240429120534"
}
```

### GET /get_order/<order_id>
Получает информацию о заказе

### POST /update_order/<order_id>
Обновляет статус заказа

## 🐛 Решение проблем

### Проблема: "TELEGRAM_BOT_TOKEN не установлен"
**Решение:** Проверьте, что файл `.env` существует и содержит корректный токен

### Проблема: Ссылка на бота не работает
**Решение:** 
- Убедитесь, что `TELEGRAM_BOT_USERNAME` установлена правильно
- Проверьте, что бот запущен и виден в Telegram

### Проблема: Администратор не получает уведомления
**Решение:**
- Проверьте, что `TELEGRAM_CHAT_ID` установлена на ваш личный ID
- Убедитесь, что вы подписаны на бота (`/start`)

### Проблема: "ModuleNotFoundError: No module named 'telegram'"
**Решение:** 
```bash
pip install python-telegram-bot==20.3
```

### Проблема: Flask приложение не запускается
**Решение:**
- Проверьте, что Python 3.8+ установлен
- Проверьте синтаксис `.env` файла
- Запустите с флагом debug: `python main.py`

## 🔐 Безопасность

⚠️ **Важные замечания:**

1. **Никогда не делитесь токеном бота** - он позволит кому-то контролировать вашего бота
2. **Используйте `.env` файл** - не коммитьте его в GitHub
3. **Измените `SECRET_KEY`** на случайную строку в production
4. **Используйте HTTPS** при развёртывании на production сервере
