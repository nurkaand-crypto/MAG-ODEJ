# 🛍️ МАГ-ОДЕЖ - Магазин одежды и обуви

Полнофункциональный интернет-магазин с корзиной, фильтрами товаров, системой уведомлений через Telegram и Email.

## ✨ Возможности

- 📦 **Каталог товаров** с фильтрацией по категориям и цене
- 🛒 **Интерактивная корзина** с возможностью добавления/удаления товаров
- 💰 **Расчёт стоимости** с учётом доставки и промокодов
- 📱 **Информация о магазине и сотрудниках** на странице "О нас"
- 🤖 **Telegram бот** для уведомления о новых заказах
- 📧 **Email уведомления** клиентам и администратору
- 💾 **Локальное хранилище** заказов (localStorage для корзины)
- 📱 **Адаптивный дизайн** для всех устройств

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка Telegram бота

1. Откройте Telegram и напишите `@BotFather`
2. Используйте команду `/newbot`
3. Следуйте инструкциям, чтобы создать бота
4. Скопируйте полученный **Token**

5. Напишите своему боту любое сообщение
6. Откройте браузер: `https://api.telegram.org/bot<ВАШ_TOKEN>/getUpdates`
7. Найдите `"id"` в ответе - это ваш **Chat ID**

### 3. Настройка Email (Gmail)

1. Откройте [Google Account Security](https://myaccount.google.com/security)
2. Включите **двухфакторную аутентификацию**
3. Создайте **пароль приложения** (App Password)
4. Скопируйте пароль приложения

### 4. Обновите конфиг в main.py

Откройте `main.py` и замените:

```python
TELEGRAM_BOT_TOKEN = "ВАШ_TOKEN_ОТ_BOTFATHER"
TELEGRAM_CHAT_ID = "ВАШ_CHAT_ID"
EMAIL_SENDER = "ваш_email@gmail.com"
EMAIL_PASSWORD = "ВАШ_ПАРОЛЬ_ПРИЛОЖЕНИЯ"
```

### 5. Запуск сервера

```bash
python main.py
```

Откройте браузер: `http://localhost:5000`

## 🐛 Решение проблем

### Ошибка: "ModuleNotFoundError: No module named 'flask'"
```bash
pip install -r requirements.txt
```

### Ошибка: "Telegram BOT TOKEN не установлен"
- Убедитесь, что вы заменили значения в main.py
- Проверьте, что токен скопирован правильно

### Email не отправляется
- Проверьте, что включена двухфакторная аутентификация в Gmail
- Используйте пароль приложения, а не обычный пароль
- Разрешите доступ менее защищённых приложений

### Корзина не сохраняется
- Проверьте, что localStorage включён в браузере
- Используйте браузер с поддержкой localStorage (все современные)
