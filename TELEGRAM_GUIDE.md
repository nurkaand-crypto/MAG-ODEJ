# 🤖 ИНТЕГРАЦИЯ С TELEGRAM БОТОМ

## Как это работает

1. **Клиент добавляет товары** в корзину на сайте
2. **Нажимает "Оформить заказ"** и вводит только своё имя
3. **Появляется кнопка "Продолжить в Telegram"**
4. **Клиент переходит в Telegram бот** где может общаться и получить дополнительную информацию
5. **Заказ отправляется администратору** в Telegram для обработки

---

## 🔧 Быстрая Настройка

### Шаг 1: Получите Telegram Bot Token

1. Откройте Telegram и найдите `@BotFather`
2. Отправьте `/newbot`
3. Следуйте инструкциям:
   - Название бота: `MAG ODEZH Shop Bot`
   - Username бота: `mag_odezh_bot` (или другой, заканчивающийся на `_bot`)
4. **Скопируйте полученный токен** (выглядит как: `123456789:ABCdefGHIjklmno-PQRstuvWXYZ`)

### Шаг 2: Получите ваш Chat ID (для администратора)

1. Отправьте своему новому боту команду `/start`
2. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
   Замените `<ВАШ_ТОКЕН>` на ваш токен
3. **Найдите в ответе** строку `"id": 123456789`
4. **Скопируйте числовую часть** - это ваш Chat ID

### Шаг 3: Обновите Конфиг

Откройте `main.py` и найдите строки:

```python
TELEGRAM_BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
TELEGRAM_CHAT_ID = "YOUR_CHAT_ID"
```

Замените на ваши данные:

```python
TELEGRAM_BOT_TOKEN = "123456789:ABCdefGHIjklmno-PQRstuvWXYZ"
TELEGRAM_CHAT_ID = "987654321"
```

### Шаг 4: Запустите Сервер

```bash
python main.py
```

**Готово!** Бот теперь работает! 🎉

## 📱 Команды Telegram Бота

Когда пользователь запустит бота, доступны команды:

| Команда | Что делает |
|---------|-----------|

```

```

## 💬 Как Работает Оформление Заказа

### На Сайте

1. Пользователь добавляет товары в корзину
2. Открывает корзину
3. Вводит **только своё имя** (Email и адрес больше не нужны!)
4. Нажимает кнопку **"Оформить заказ"**

### На Сервере

Создаётся заказ и отправляется:
- 📤 Генерируется ссылка на Telegram бота
- 📬 Отправляется уведомление администратору
- 🔗 Показывается кнопка "Продолжить в Telegram"

### В Telegram

1. Клиент нажимает кнопку и попадает в бот
2. Может получить справку командой `/help`
3. Может получить информацию о заказе
4. Администратор получает уведомление и может ответить

## 🔌 Продвинутая Настройка (Webhook)

Если вы хотите, чтобы бот **автоматически** отвечал на сообщения пользователей (а не только при открытии), нужно настроить webhook.

### Способ 1: Автоматическая Настройка

```bash
python setup_telegram_webhook.py
```

Введите:
- Telegram Bot Token
- Webhook URL (например: `https://example.com/telegram_webhook`)

### Способ 2: Ручная Настройка

Откройте в браузере:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://example.com/telegram_webhook
```

Замените:
- `<ТОКЕН>` на ваш токен
- `https://example.com` на ваш реальный адрес

### Для Локального Тестирования (Ngrok)

1. Установите [ngrok](https://ngrok.com/)
2. Запустите:
   ```bash
   ngrok http 5000
   ```
3. Скопируйте URL (например: `https://abc123.ngrok.io`)
4. Используйте этот URL в webhook:
   ```
   https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://abc123.ngrok.io/telegram_webhook
   ```

## 🐛 Решение Проблем

### Проблема: Бот не отправляет уведомления

**Решение:**
1. Проверьте, что токен верный
2. Проверьте, что Chat ID верный
3. Убедитесь, что вы отправили боту хотя бы одно сообщение (`/start`)
4. Проверьте логи сервера (они должны показать попытку отправки)

### Проблема: Webhook не работает

**Решение:**
1. URL должен начинаться с `https://` (не `http://`)
2. URL должен быть доступен из интернета
3. Используйте ngrok для локального тестирования
4. Проверьте URL доступен: откройте в браузере

### Проблема: Кнопка Telegram не работает

**Решение:**
1. Проверьте что у вас есть Telegram установлен
2. Убедитесь что username бота заканчивается на `_bot`
3. Используйте `/start` команду вручную если кнопка не работает
