🚀 БЫСТРЫЙ СТАРТ (3 ШАГА):

Шаг 1️⃣  Telegram Токен
─────────────────────────────────────
@BotFather → /newbot → скопируйте токен
Формат: 123456789:ABCdefGHIjklmno

Шаг 2️⃣  Chat ID
─────────────────────────────────────
https://api.telegram.org/bot<ТОКЕН>/getUpdates
Найдите числовой "id" - это ваш Chat ID
Формат: 987654321

Шаг 3️⃣  Конфигурация
─────────────────────────────────────
Откройте main.py и замените:

БЫЛО:
  TELEGRAM_BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
  TELEGRAM_CHAT_ID = "YOUR_CHAT_ID"

СТАЛО:
  TELEGRAM_BOT_TOKEN = "123456789:ABCdefGHIjklmno"
  TELEGRAM_CHAT_ID = "987654321"

🎯 КАК РАБОТАЕТ НОВАЯ СИСТЕМА:

Пользователь:
  1. Добавляет товары в корзину
  2. Нажимает "Оформить заказ"
  3. Вводит только ИМЯ
  4. Видит кнопку "Продолжить в Telegram"
  5. Переходит в Telegram бот
  6. Общается с администратором

Администратор:
  1. Получает уведомление о заказе в Telegram
  2. Видит все товары и сумму
  3. Может ответить клиенту в боте

❓ ВОПРОСЫ?

1. Бот не отправляет сообщения?
   - Проверьте токен и Chat ID в main.py
   - Убедитесь что вы отправили /start боту

2. Кнопка не открывается?
   - Убедитесь что установлен Telegram
   - Проверьте что bot username правильный

3. Всё не работает?
   - Посмотрите логи сервера (терминал)
   - Читайте TELEGRAM_GUIDE.md → "Решение проблем"
