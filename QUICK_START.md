# ⚡ БЫСТРЫЙ СТАРТ - Telegram боту в магазине МАГ-ОДЕЖ

## 🎯 Суть интеграции

Когда посетитель вашего магазина нажимает "Оформить заказ":
1. ✅ Заказ создаётся на сервере
2. ✅ Автоматически открывается Telegram бот
3. ✅ Все товары и цены отправляются в бот
4. ✅ Покупатель подтверждает покупку в Telegram
5. ✅ Вы получаете уведомление об изменении

---

## 📋 Чеклист (5 простых шагов)

### ✅ Шаг 1: Создайте Telegram бота (2 минуты)

1. Откройте Telegram и найдите `@BotFather`
2. Отправьте `/newbot`
3. Введите имя бота: `МАГ-ОДЕЖ бот`
4. Введите username: `mag_odezh_bot` (должен заканчиваться на `_bot`)
5. **Скопируйте токен**, например:
   ```
   123456789:ABCDEFGHijklmnopqrstuvwxyz-1234567890
   ```

### ✅ Шаг 2: Получите ваш Chat ID (1 минута)

Есть два способа:

**Способ А (легче):**
1. Напишите `@userinfobot` в Telegram
2. Отправьте ему любое сообщение
3. Скопируйте значение из поля `"id": 123456789`

**Способ Б (альтернатива):**
```bash
# Замените YOUR_TOKEN на ваш токен
curl https://api.telegram.org/botYOUR_TOKEN/getUpdates
```

### ✅ Шаг 3: Установите зависимости (1 минута)

```bash
pip install -r requirements.txt
```

Или если хотите использовать виртуальное окружение:

```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux/Mac:
source venv/bin/activate

pip install -r requirements.txt
```

### ✅ Шаг 4: Заполните .env файл (1 минута)

1. Откройте файл `.env` в текстовом редакторе
2. Заполните значения:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCDEFGHijklmnopqrstuvwxyz-1234567890
TELEGRAM_BOT_USERNAME=mag_odezh_bot
TELEGRAM_CHAT_ID=123456789
SECRET_KEY=change-me-to-something-random
```

3. Сохраните файл

### ✅ Шаг 5: Запустите и проверьте! (1 минута)

**Windows:**
```bash
run.bat
```

**Linux/Mac:**
```bash
bash run_unix.sh
```

**Или вручную:**
```bash
python main.py
```

Вы должны увидеть:
```
==================================================
🛍️  МАГ-ОДЕЖ - Интеграция с Telegram
==================================================
Flask запущен на http://localhost:5000
Telegram Bot Token: Установлен ✅
✅ Telegram бот инициализирован
🤖 Поток Telegram бота запущен
==================================================
```

## 🐛 Если что-то не работает

### Ошибка: "TELEGRAM_BOT_TOKEN не установлен"

```bash
# Проверьте что файл .env существует
ls -la .env

# Проверьте содержимое
cat .env

# Запустите проверку конфигурации
python check_setup.py
```

### Ошибка: "ModuleNotFoundError: No module named 'telegram'"

```bash
pip install python-telegram-bot==20.3
```

### Ошибка: "Port 5000 is already in use"

Порт занят другим приложением. Либо закройте его:

```bash
# Windows
netstat -ano | findstr :5000
# Linux/Mac
lsof -i :5000
```

Или измените порт в `main.py`:
```python
app.run(port=5001)
```

### Ссылка на бота не работает

Проверьте, что:
- `TELEGRAM_BOT_USERNAME` правильный (без @)
- Бот запущен (`/start` в поиске должен его найти)
- Интернет подключен

## 🎯 Что дальше?

1. Купите доменное имя и хостинг
2. Настройте SSL сертификат (Let's Encrypt)

4. Настройте Telegram Webhook вместо polling
5. Используйте реальную БД (PostgreSQL) вместо памяти
